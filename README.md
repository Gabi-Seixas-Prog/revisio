
# Revisão – Farmacocinética

Este repositório reúne conteúdos estruturados em formato de "micro-posts científicos",
voltados para revisão de conceitos fundamentais e avançados de Farmacocinética.

📌 Objetivo:
– Consolidar raciocínio quantitativo
– Treinar comunicação técnica
– Criar material reutilizável para ensino

Tópicos abordados:
- Modelos compartimentais
- Constante de eliminação (k)
- Meia-vida (t1/2)
- AUC
- Clearance
- Volume de distribuição
- Curva de Gauss e normalização de notas (contexto académico)

Atualizações semanais.
